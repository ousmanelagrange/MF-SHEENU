# Sheenu mobile (Expo)

Phase 1 : connexion, choix de la famille, liste des personnes par préséance, fiche navigable (parents, conjoints, enfants, fratrie), lien de parenté avec soi.

```bash
npm install
EXPO_PUBLIC_API_URL=http://<IP-de-votre-ordinateur>:8000 npx expo start
```

Ouvrez Expo Go sur le téléphone et scannez le QR code.
